# HR Analytics Dashboard
###Project title
---
📊 HR Analytics — Employee Attrition & Workforce Insights
Interactive Power BI dashboard to analyze employee attrition and workforce characteristics.

###Purpose
---
Turn raw HR records into a concise, interactive Power BI report that helps HR teams and managers identify attrition patterns, spot at-risk groups, and make data-driven retention decisions.

###Tech Stack
---
The dashboard was built using the following tools and technologies:
- 📈 Power BI Desktop - Main data visualization platform used for report creation.
- 🪄 Power Query - Data transformation and cleaning layer for reshaping and preparing the data.
- 🗂️ File Format - .pbix for development and .png for dashboard previews.

###Features & Highlights
---
- Used 6 KPI Cards to show total employees, Attrition count, Attrition rate, Avg. tenure, and Avg. salary.
- Potrayed Attrition breakdowns by Job Role, Department, Salary band, Education, Gender, and Age group.
- Used Donut Chart, Stacked Column Chart, Stacked Bar Chart, Area Chart, Matrix and Tree Map to display visualizations of the columns that contribution to attrition rate.
